Link Inspector
Select a linked line, PolyFill, or perspective guide.
Wheel zooms • Space + drag pans • H hides selected • Shift+H unhides all • . / , cycle hidden objects • Shift+> timed show • Ctrl/Cmd bypasses snapping/free page points • Presets: 1 Construction, 2 Outline, 3 Fill, 4 Reference, 5 Hidden, 6 Center • Select line then M/type length in mm • Line endpoints link when snapped to endpoints, intersections, or line bodies • Perspective guides are thicker red rays with vanishing points starting near the page/view extents • Vanishing points snap only to stable endpoints/corners while dragging; hold Shift for grid, Ctrl/Cmd for free • Perspective-linked construction lines move as a synced group instead of leaving one end pinned to the page • Press L while drawing/in line mode to auto-link overlaps/intersections • Snip + Join uses the selected line, or the last drawn line if none is selected; hover near the crossing line/intersection, then press J or ✂ to snip/link them. PolyFill corners snap/link to those joints • Start a line from a shape corner/end and draw toward a red vanishing point to make it follow that source + point proportionally; a red dashed helper ray is added from the line end to the VP • PolyFill: click 3+ corners, then Enter/double-click/right-click/click near the first point; if SVG reveal is active it may be hidden until its reveal step • Circles and arcs use tangent projection points for perspective guides • Right-click: finish PolyFill / reset Arc • Ctrl/Cmd + Z undo • Ctrl/Cmd + Y redo • Delete removes selected • Link Inspector: select an object, then Check or Repair to see green/orange/red link markers
